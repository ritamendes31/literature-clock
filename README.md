# Literature Clock

Tells the time with a quote from a book that mentions the current minute. Works offline once loaded and can be added to the iPhone home screen.

Quotes come from [JohsEnevoldsen/literature-clock](https://github.com/JohsEnevoldsen/literature-clock), originally collected by The Guardian, licensed [CC BY-NC-SA 2.5](http://creativecommons.org/licenses/by-nc-sa/2.5/). All quotes are included, some of which contain adult content.
